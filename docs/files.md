# 附件与卷宗

[← 文档目录](README.md) · [English](en/files.md)

- 点击、拖入或粘贴图片、文本、代码、PDF、Office 等文件；PDF、DOCX、PPTX、XLSX 等会先在浏览器本地提取正文，图片按视觉内容发送，其他二进制文件使用兼容接口的文件内容格式
- 附件原件与对话一起落在存储目录的 `附件/`（落盘不成时暂存浏览器 IndexedDB，接上桥接后推进目录）；单件 256 MB、单次最多 10 件；超过 32 MB 的文件（没抽出正文的）不随消息整份送给模型，与压缩包一样只给本机原件路径，由模型用工具读；没人用的原件（对话删了、附件撤了）放满一天后清掉；收入卷宗的单件同为 256 MB；PDF 解析器与中文字符映射随项目本地分发
- 「卷宗」：跨对话保存常用文件。卷宗就是存储目录里的 `卷宗/`（默认 `~/.yan/卷宗/`），页面上的卷宗即这个目录的视图：拖入（只认从页面之外拖来的；卷宗里的图、案上的附件在页内拖动不会又收一份；拖进文件夹照原样建夹收入，同名的另取名、点开头的跳过；案上只放文件，拖来的夹请进卷宗）、按「藏」收入的文件落盘到这里，没绑目录的对话里模型写出的成品也在这里；可预览、下载、删除；要随消息送出，从输入框的「＋」里选「卷宗」（网页与脚本文件一律按纯文本在沙箱里给出，不会以本站身份运行）。模型为了做出成品而写的脚本与中间文件放在卷宗里的隐藏目录 `.草稿/<对话id>/`，页面不列它；删除对话时随之清掉，卷宗页顶上也有「草稿 n 处 · 大小 · 清理」。一答的成品是答复里链到的本机文件：模型把要交给你看的报告、表格、图写成链接（`[报告](报告.md)`），言与行都一样，答末的「成品 n 件」卡就列这几件（落在卷宗里的另注「已入卷宗」）——列哪几件由模型定，解压出的一堆、顺手改的代码、别的对话同时写进卷宗的都不会混进来。一件一行：类型、文件名、大小，右侧「预览」与「下载」；正文里那个链接点了也是预览。之后在卷宗里删掉了的，那一行留着但标成「已移出卷宗」、收起两个按钮。「预览」是就地的悬浮预览，不必先下载：图片直接看，PDF 交给浏览器自带的阅读器，CSV / TSV 排成表格，Markdown 渲染，文本与代码按原样，Word / Excel / PPT 在本机抽出正文，网页进与页内交互预览同一个隔离沙箱；卷宗页的每件文件也有这个「预览」。Markdown 里的图与链接从文件所在的那一层算；文档或图挪过、原路取不到时，认同名里离得最近的一件（一样近的不猜），文件本身不改，还认不出的图留下说明文字。卷宗里的文档（PDF、Office、文本）对言与行的每段对话都可读：模型用 `read_document` 翻阅，用到时才取回并在本机抽正文，设置里可关。侧栏对话「⋯」里的「导出」把整段对话存成 Markdown（含行迹摘要与成品）落到卷宗。按名搜索、按 画 / 文 / 音 / 影 / 卷 过滤；删除对话不会删掉卷宗中的成品
- 听音：卷宗或附件里的音频点「预览」即是听音——一曲画成一笔圆相，笔的粗细随声强弱，笔尖即此刻，可上一首、下一首（同一处的音频连成一列，放完接下一首，末一首放完回到头一首）。点空白或按 Esc 是「收」：曲子照放，正文右上角垂下一缕墨线坠一小圆相，随声而摆，点它垂下一张纸签（题名、时刻、上下首、奏 / 止），点题名回到整页；整页上的 × 才是「停」。放音只有页里常驻的一处，往后别处要放音交一条 track 给 `listenLoad` 即可（`src/25-listen.js`）
- 多轮对话只有本轮要回答的那条消息携带附件原件，此外，此前最近一回带图的那一问，图片也整份带着（「刚才那张图」才答得上）；更早消息里的文本与提取正文改为摘要（超过 3000 字截断），图片与二进制原件改为占位说明。若要让模型再次看到旧图片，可从卷宗重新置于案上
- 本轮的文本附件与提取正文也有个上限：约为模型窗口的一成半（没填窗口按 24k token），超过的只随消息给一行「文件名、字数」，模型要看就用 `read_document` 按页或关键词取，不会把整本书硬塞进提示撑爆窗口；附件入库时顺手记下字数估算，右下角的上下文计数按它算
