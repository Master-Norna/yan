# 附件与卷宗

[← 文档目录](README.md) · [English](en/files.md)

- 点击、拖入或粘贴图片、文本、代码、PDF、Office 等文件；PDF、DOCX、PPTX、XLSX 等会先在浏览器本地提取正文，图片按视觉内容发送；没抽出正文的小 PDF 仍可作为文件发送，须接口支持 PDF；其他二进制格式一般只给文件说明
- 附件原件与对话一起落在存储目录的 `附件/`（落盘不成时暂存浏览器 IndexedDB，接上桥接后推进目录）；单件 256 MB、单次最多 10 件；超过 32 MB 的文件（没抽出正文的）不随消息整份送给模型，与压缩包一样只给本机原件路径，由模型用工具读；删对话或撤附件时，不再被引用的原件会清掉；另会清理已存满一天却无人引用的遗留原件；收入卷宗的单件同为 256 MB；PDF 解析器与中文字符映射随项目本地分发
- 「卷宗」：跨对话保存常用文件。卷宗就是存储目录里的 `卷宗/`（默认 `~/.yan/卷宗/`），页面上的卷宗即这个目录的视图：拖入（只认从页面之外拖来的；卷宗里的图、案上的附件在页内拖动不会又收一份；拖进文件夹照原样建夹收入，同名的另取名、点开头的跳过；案上只放文件，拖来的夹请进卷宗）、按「藏」收入的文件落盘到这里，没绑目录的对话里模型写出的成品也在这里；点条子即预览，条尾悬停露出下载、改名、删除三枚笔意小画；要随消息送出，从输入框的「＋」里选「卷宗」。模型为了做出成品而写的脚本与中间文件放在卷宗里的隐藏目录 `.草稿/<对话id>/`，页面不列它；删除对话时随之清掉，卷宗页顶上也有「草稿 n 处 · 大小 · 清理」。一答的成品是答复里链到的本机文件：模型把要交给你看的报告、表格、图写成链接（`[报告](报告.md)`），言与行都一样，答末的「成品 n 件」卡就列这几件（落在卷宗里的另注「已入卷宗」）——列哪几件由模型定，解压出的一堆、顺手改的代码、别的对话同时写进卷宗的都不会混进来。一件一行：类型、文件名、大小，条尾一枚下载的笔意小画；点条目即预览，正文里那个链接点了也是同一条路。之后在卷宗里删掉了的，那一行留着但标成「已移出卷宗」、不再可点。预览是就地的悬浮预览，不必先下载：图片直接看，PDF 交给浏览器自带的阅读器，CSV / TSV 排成表格，Markdown 渲染，文本与代码按原样，DOCX / ODT、XLSX / ODS、PPTX / ODP 在本机抽取结构化内容（标题、列表、表格、工作表与幻灯片；演示文稿一次只显示一页，底下是一排朱点（一页一点，离当前越远越淡越小），点它或用左右方向键翻页；PPTX 按原幻灯片比例显示，标题、文本框、讲者备注与可识别的图片与图表按结构抽出（折线、面积、柱、饼、环形、雷达照包里带着的数据重画；同一张图里两组以上、每组都带系列的组合图与智能图形仍是一块虚线框）），不还原原始版式；旧版 DOC / XLS / PPT 不能这样预览；网页进与页内交互预览同一个隔离沙箱，不联网、不以本站身份运行；卷宗页上点条子打开的就是这个预览。Markdown 里的图与链接从文件所在的那一层算；文档或图挪过、原路取不到时，认同名里离得最近的一件（一样近的不猜），文件本身不改，还认不出的图留下说明文字。卷宗里的文档（PDF、Office、文本）对言与行的每段对话都可读：模型用 `read_document` 翻阅，用到时才取回并在本机抽正文，可在「设置 → 工具 → 卷宗对模型可读」关闭这一翻阅入口。侧栏对话「⋯」里的「导出」把整段对话存成 Markdown（含行迹摘要与成品）落到卷宗。按名搜索、按 画 / 文 / 音 / 影 / 卷 过滤；删除对话不会删掉卷宗中的成品
- 听音：卷宗或附件里的音频点开（卷宗点条子，附件点「预览」）即是听音——一曲画成一笔圆相，笔的粗细随声强弱，笔尖即此刻，可上一首、下一首（同一处的音频连成一列，放完接下一首，末一首放完回到头一首）。点空白或按 Esc 是「收」：曲子照放，正文右上角垂下一缕墨线坠一小圆相，随声而摆，点它垂下一张纸签（题名、时刻、上下首、奏 / 止），点题名回到整页；整页上的 × 才是「停」。放音只有页里常驻的一处，往后别处要放音交一条 track 给 `listenLoad` 即可（`src/25-listen.js`）
- 多轮对话只有本轮要回答的那条消息携带附件原件，此外，此前最近一回带图的那一问，图片也整份带着（「刚才那张图」才答得上）；此前的文本与提取正文保留开头至多 3000 字；再早的图片与普通二进制原件只留占位说明，压缩包仍可给出本机路径。若要让模型再次看到旧图片，可从卷宗重新置于案上
- 本轮的文本附件与提取正文也有个单件上限：约为模型窗口的一成半，最低 4000 token（没填窗口按 24k token），超过的只随消息给一行「文件名、字数」，模型要看就用 `read_document` 按页或关键词取，不会把整本书硬塞进提示撑爆窗口；附件入库时顺手记下 token 估算，右下角的上下文计数按它算
