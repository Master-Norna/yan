# 录 · 记忆

[← 文档目录](README.md) · [English](en/memory.md)

- 记忆是一条条关于你的话（偏好、身份、约定、进行中的事），按类归好，跨对话都带着。开关在设置的「专司」里：给「记忆」配一份接口与模型，配好了才带、才整理；关掉即不带不记，条目仍在
- 带进对话：整份记忆放进系统提示，模型不必去翻。每段对话头一问时定格，此后整理都不改它，系统提示不变，前面的缓存接得上。记多少不设上限：一条一事、相关的并进已有那条，长得自然慢
- 整理：每一答落定，专司「记忆」就在后台读这段还没整理过的问答，不必离开这段，对照现有记忆答一份增删改——补记、合并、删去被推翻的；没提到的条目一字不动。它只读你说的话与模型的答复，不读网页、文件这些工具结果。整理改的是往后各段带的那份，这段已定格的不变；页面关了没来得及、或没整理成的，下回开页补上。只从开起记忆那一刻算起，此前的旧对话不拿去整理。改了几条，提示一句；花的墨记进用量卡的「记忆」
- 要记、要忘：对模型直说即可，这一答之后的整理会照办。模型自己不增删记忆，系统提示里交代了有人整理，它便不另想办法去记。主答与旁注带着记忆，帮手不带
- 旧对话：`search_conversations` 按关键词查（不给关键词即按时间列出最近的），`read_conversation` 分段读一段的主线；这两件常给，与记忆开不开无关。读过的列在回复底部的「出处」里，点开即回那一段
- 设置页「记忆」一栏可改、可删、可手记、可归类；条目随备份导出、导入时按 id 与原文去重
