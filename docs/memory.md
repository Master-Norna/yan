# 录 · 记忆

[← 文档目录](README.md) · [English](en/memory.md)

- 记忆是跨对话有用的用户背景、偏好、约定、计划与经历，按类各成一份全文，只存于本机。主模型自行决定何时记入、更新与忘记，无需另配模型；开关在设置 → 记忆的「带进对话」，关掉即不带不记，已存内容仍在
- 两层：跨对话的一层随设置保存；只在某个目录成立的做法与经验，执事记在那个目录的 `.yan/记忆.md`，在那里每一问都附着，不受这里的开关管（见[言与行 · 记忆](work.md#记忆)）
- 带进对话：每一问把最新的整份记忆放进系统提示，一类一段；同一答的工具往来沿用这一份。其他对话记下的、你在设置里改的，下一问便可见。内容不变时提示不变；记忆更新会影响从变化位置起的提示缓存。记多少不设上限
- 记：主模型用 `remember` 写一类改后的全文，仍成立的照留，新的并入，过时的、你要它忘的删去；空串即删去这一类。当前情况只留有效版本，重要变化可注明发生日期；一类可分段、分行，不必挤成一大段，也不重复追加整份旧背景。只有主模型能写，旁注只读得到全局记忆，帮手不带
- 写入按本答读到的版本核对：某类已被其他对话或设置修改时，这次覆盖不执行，最新正文交回主模型重写。真正落盘时还会再核对一次：那段时间里若另一个浏览器改过这一类，这次写入同样不生效，以落盘的那份为准交回重写。成功写下的正文也当场交回，下一轮工具调用可沿用。没有后台自动整理或额外的记忆模型请求
- 旧对话：`search_conversations` 按关键词查（不给关键词即按时间列出最近的），`read_conversation` 分段读一段的主线；这两件常给，与记忆开不开无关。读过的列在回复底部的「出处」里，点开即回那一段
- 设置页左列各类，右边是选中那一类的全文；点「修改」编辑，改空即删类。类名可改，改作已有之名即并类。记忆随备份导出，导入时同名一类的全文接上，已有的行不重接；旧版一条一事的同类内容读入时并成一份。旧「记忆优化」的开关迁到这里，接口与模型配置撤去，已存的记忆保留
