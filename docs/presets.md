# 预设

[← 文档目录](README.md) · [English](en/presets.md)

一套做法打包成一个预设：提示词、给哪几组工具（联网、计算、生图、指令与文件、翻文档、请示、记忆与旧谈、差遣）与哪几个 MCP 服务、用哪个模型、指令权限。以言为底做一个专门的 Agent——接入某个项目的 MCP、配一段专门的提示词——即是添一个预设。

- 在设置 → 预设里添、改、删，一张卡一个，改了即存；内置工具组与 MCP 服务分别勾选；任一栏全勾上，今后新添到该栏的也一并给。
- 在输入框旁的模型菜单里选用：选了的对话都照这一套，模型按钮上标着预设名；普通新对话沿用最近选用或打开的对话所用的预设；在组内新起时优先用组指定的预设。选「本色」即不加预设。
- 预设的提示词排在系统提示最前，其后是言自己的几段；工具只交给模型挑中的那几组，没挑中的 MCP 服务，模型照着名字调来也不跑。带了模型或权限的，选用时一并换上；切回「本色」只撤预设，不还原当时换上的模型及权限。
