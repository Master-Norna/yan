# 预设

[← 文档目录](README.md)

一套做法打包成一个预设：提示词、给哪几组工具（联网、计算、指令与文件、翻文档、请示、记忆与旧谈、差遣）与哪几个 MCP 服务、用哪个模型、指令权限。以言为底做一个专门的 Agent——接入某个项目的 MCP、配一段专门的提示词——即是添一个预设。

- 在设置 → 预设里添、改、删，一张卡一个，改了即存；工具与 MCP 全勾上时存成「全给」，往后新添的组与服务也跟着给。
- 在输入框旁的模型菜单里选用：选了的对话都照这一套，模型按钮上标着预设名；新对话照上回选的。不选即言的本色。
- 预设的提示词排在系统提示最前，其后是言自己的几段；工具只交给模型挑中的那几组，没挑中的 MCP 服务，模型照着名字调来也不跑。带了模型或权限的，选用时一并换上。
- 旧版写在模型配置里的 system prompt 挪成一个同名预设（带着那个模型），模型配置里不再有这一栏。
