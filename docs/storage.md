# 存储与备份

[← 文档目录](README.md)

桥接在线时，对话、卷宗、附件与配置都落在一个存储目录里（默认 `~/.yan/`）：`对话/` 一段对话一个 JSON 文件、复制即备份，`卷宗/` 是成品与收进来的文件，`附件/` 是对话里附件的原件（一件一个原件加一份同名 `.json` 元数据），`配置.json` 是设置、模型配置（含 API Key）、记忆与草稿——几个浏览器共用这一份，不再各存一套（两处同开、各改各的也不互相盖：写之前先比磁盘上的那份，别处改过就按上次对齐的那份三方合并——自己改的取自己的、没改的取对方的；在别处删了的对话，这边也跟着删，不会推回去复活）；浏览器里那份只是缓存与没桥接时的暂存，接上后与存储目录对齐。设置 → 通用里只有一个「存储位置」，换到别处时整份拷过去（那里已有言的数据就直接用），旧处原样留着；头一回开这一版时，旧的 `~/言/对话`、`~/言/卷宗`（或设过的自定义目录）会拷进来，旧处也留着。没桥接时附件原件暂存浏览器的 IndexedDB，接上后推进 `附件/`。不经任何云端

## 备份

- 备份导出与导入：导出时可勾选「含附件原件」；导入采用合并策略（按 id 跳过已存在的对话 / 模型 / 卷宗，并合并未冲突的草稿）；备份不含 API Key
