# Memory

[← Docs](README.md) · [中文](../memory.md)

- Memory is a set of short notes about you (preferences, identity, agreements, ongoing work), filed under categories and carried across chats. It's switched on under **Duties** in settings: give **Memory** an API and a model, and only then is it included and tidied. Turned off, nothing is included or recorded, and the items stay
- Bringing it into chats: the whole memory goes into the system prompt, so the model doesn't have to look anything up. It's frozen at each chat's first message; tidying elsewhere or an item saved in this chat doesn't change it, so the system prompt stays the same and the cache keeps working. It can be included whole because it's short: the total budget is 3,000 characters
- Tidying: whenever an answer settles, the Memory duty reads the chat's exchanges not yet tidied in the background — no need to leave the chat — and, against the current memory, answers with a list of additions, updates and deletions — adding what's new, merging, removing what's been overturned, and keeping within the budget; items it doesn't mention stay word for word. It reads only what you said and the model's replies, not tool results such as web pages or files. Tidying changes the memory later chats carry; this chat's frozen copy stays as it was. Anything missed because the page closed, or that failed to tidy, is caught up next time the page opens. Counting starts when memory is turned on; older chats aren't tidied. A short notice says what changed, and the tokens are counted under **Memory** on the usage card
- Saving on the spot: the model can also save an item with `remember` (with `replaces` to rewrite an existing one) or delete one with `forget`, visible under Steps; tidying doesn't depend on it and fills in from the chat. Only the main model gets these; side notes only see the memory, and subagents don't carry it
- Past chats: `search_conversations` searches by keyword (with no keyword it lists the most recent), and `read_conversation` reads a chat's main thread in parts. These two are always available, whether memory is on or not. Chats read are listed under **Sources** at the bottom of the reply, each opening that chat
- The **Memory** tab in settings lets you edit, delete, add and recategorize entries; entries are included in backup export, and deduplicated by id and text on import
