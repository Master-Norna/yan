# Memory

[← Docs](README.md) · [中文](../memory.md)

- Memory is a set of short notes about you (preferences, identity, agreements, ongoing work), filed under categories and carried across chats. It's switched on under **Duties** in settings: give **Memory** an API and a model, and only then is it included and tidied. Turned off, nothing is included or recorded, and the items stay
- Bringing it into chats: the whole memory goes into the system prompt, so the model doesn't have to look anything up. It's frozen at each chat's first message; later tidying doesn't change it, so the system prompt stays the same and the cache keeps working. There's no length cap: one item per fact, and related facts merge into the existing item, so it grows slowly
- Tidying: whenever an answer settles, the Memory duty reads the chat's exchanges not yet tidied in the background — no need to leave the chat — and, against the current memory, answers with a list of additions, updates and deletions — adding what's new, merging, removing what's been overturned; items it doesn't mention stay word for word. It reads only what you said and the model's replies, not tool results such as web pages or files. Tidying changes the memory later chats carry; this chat's frozen copy stays as it was. Anything missed because the page closed, or that failed to tidy, is caught up next time the page opens. Counting starts when memory is turned on; older chats aren't tidied. A short notice says what changed, and the tokens are counted under **Memory** on the usage card
- Remembering and forgetting: just tell the model; the tidying after that answer takes care of it. The model doesn't add or delete items itself; the system prompt tells it someone tidies, so it doesn't look for its own way to save things. The main answer and side notes carry the memory; subagents don't
- Past chats: `search_conversations` searches by keyword (with no keyword it lists the most recent), and `read_conversation` reads a chat's main thread in parts. These two are always available, whether memory is on or not. Chats read are listed under **Sources** at the bottom of the reply, each opening that chat
- The **Memory** tab in settings lets you edit, delete, add and recategorize entries; entries are included in backup export, and deduplicated by id and text on import
