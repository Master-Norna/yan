# 权限与沙箱

[← 文档目录](README.md)

本机桥接仅监听 `127.0.0.1`，只受理发往本机地址的请求（防 DNS 重绑定），别的网站连模型转发也借不了道；指令逐条可见，权限分问而后行 / 审而后行 / 径行三档，默认逐条请示；默认套着沙箱（问而后行里从严、拦下的转为请示，审而后行与径行只守系统本身）；导出的备份不含 API Key

## 三档权限

指令有三档权限，言与行都可在输入框旁循环切换，欢迎页小签与「设置 → 工具」决定新对话默认：**问而后行**——明确只读的开发与系统检查径直执行（允许 Select / Sort / Format / JSON 等纯展示管道），其余从输入框上方浮出「请示」，可运行、跳过或径行；**审而后行**——不弹请求、不另调模型，由桥接代审：常规开发、依赖安装、Git（含回退与清理）、联网、进程、整机查看、写到工作目录之外一概放行，只把提权、账户 / 服务 / 防火墙 / 安全设置、磁盘与启动配置、藏字的指令、整目录删除、往 Windows / Program Files 这类系统目录里写等明确会伤及系统或难以恢复的动作当场回绝；**径行**——不再加这层审查。三档由严到宽单调：径行 ≥ 审而后行 ≥ 问而后行，沙箱也按档位分严宽（见下）。文件工具只经本机桥接执行，浏览器直连模式下不可用。

## 沙箱

言与行的指令与文件工具都套着一层沙箱，在桥接那头守、模型绕不过；它是常开的一层，只在「设置 → 工具」有一个总开关。沙箱按指令权限分两档。**宽的一档**给审而后行与径行：只守系统本身——注册表、服务、计划任务、防火墙、账户、磁盘、提权、执行策略、藏字的指令与别名、往 Windows / Program Files 这类系统目录里写；联网、写到目录之外、读 `.env`、改 `.git` 内部都放行，文件工具按「可及范围」走。**严的一档**给问而后行，下面三道；严的沙箱会拦下的指令不直接回绝，而是照样浮出请示、写明它会被拦的原因，批了这一条就在沙箱外执行，步骤上记一笔「出沙箱」。严的三道：**目录**——**改动**不出工作目录或卷宗（写、删、搬与重定向都不用 `..` 上溯、`~`、`$env:USERPROFILE` 与目录外的绝对路径），**查看**则可及整台机器——给电脑做检查本就要翻系统目录、注册表、进程与日志，锁住读等于把这件事堵死；文件工具那一路仍是目录内，不认「全盘」；`.env`、密钥与凭据文件读写皆拒，`.git` 内部不写，检索也不翻机密文件；**指令**——动系统的（注册表、服务、计划任务、防火墙、账户、磁盘、关机、提权、执行策略）、藏字的（编码指令、`Invoke-Expression`）、直接外联的（`curl` / `iwr` / `wget`，指向本机 127.0.0.1 的放行）一律拒绝，装依赖走包管理器、查资料用检索工具；**环境**——指令看不到名字像机密的环境变量（KEY / TOKEN / SECRET / PASSWORD……）。宽档拒下的指令带一句原因回给模型，照原因改写即可。外联只认真在联网的写法（`[System.Net.…]`、`New-Object Net.…`），`rg HttpClient` 这类只是搜字的不算。

这是静态筛查，不是进程隔离：脚本里的代码仍以你的权限运行（`node -e`、`python -c` 或一个脚本文件里写什么都不经筛查；在脚本里临时拼出桥接地址也能调到桥接的接口——这并不比脚本本身多出什么权限，所以桥接端口那一条只拦直接点名的写法），`Start-Process` 起的进程会脱离进程树，停止生成与超时都收不回它。判定「这条会不会改东西」靠的是一张动词表（`Set-Content`、`Remove-Item`、`copy`、`move`、`md`、重定向……），表外的写法漏过去就只剩三档权限那一层兜着。三档权限与沙箱彼此独立；关掉沙箱后，审而后行仍会回绝它认定的伤及系统的动作，只有径行不再加这一层，文件工具在这两档都只按「可及范围」设置。指令的超时只有默认值（120 秒）没有上限，跑不完的用「停止」收回。查看放开到整机之后，工作目录之外的普通文件（浏览器数据、聊天记录之类）也在模型读得到的范围内——只有 `.env`、密钥与凭据这类按名字认得出的另有专条。请勿将工作目录指向不希望被改动的位置。

「设置 → 工具」一栏专管模型能动手的边界：沙箱、新对话的三档指令权限、文件工具可及范围、卷宗对模型可读、工具轮次上限（按轮计，同一轮并发的几次调用只算一轮；留空即不限）。
