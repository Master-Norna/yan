# 言下

一个可连接 OpenAI 兼容接口的本地聊天前端，界面采用清简纸墨风格。

## 启动

双击 `start.cmd`，或在当前目录运行：

```powershell
npm start
```

浏览器会打开 `http://127.0.0.1:8787`。首次使用时，在“设置 → 模型”中手动填写显示名称、模型 ID、Base URL 和 API Key；项目不会读取或内置开发者电脑上的配置。

运行环境只需要 Node.js 18 或更高版本，不需要安装 npm 依赖，也不依赖任何云端后台、数据库或在线静态资源。本机进程仅监听 `127.0.0.1`，用于加载页面、转发模型请求，以及代模型执行联网检索与网页读取（拒绝访问本机与内网地址）。

在 VS Code 内使用时：

1. 通过“终端 → 运行任务”执行“言下：启动模型桥接”，并保持这个任务终端开启。
2. 按 `Ctrl+Shift+P`，运行“Simple Browser: Show”，输入 `http://127.0.0.1:8787`。
3. 在“设置 → 模型”中填写配置；可先点“获取列表”，再点“测试连接”和“测试联网”。

也可以直接预览 `Lumen Chat.dc.html`。页面会连接 `127.0.0.1:8787`；如果先开页面、后开桥接，下一次获取模型、测试或发送时会自动重连。若模型接口本身开放浏览器跨域访问，也可以不启动桥接而直接聊天，但言下联网仍需要桥接。

双击 `start.cmd` 会改为在系统浏览器打开。此时 CMD 窗口就是本机桥接进程，必须保持开启；关闭后已加载的页面暂时还在，但刷新、模型转发和联网都会失效。系统浏览器与某些 VS Code 预览扩展可能使用不同的浏览器存储，模型配置需要分别填写或通过备份导入。

可以添加多个 OpenAI 兼容接口并切换默认模型。自定义配置与聊天记录保存在浏览器的本机存储中。

## 已支持

- 多会话、新建与删除、浏览器本地保存；侧栏可按标题与正文搜索，支持置顶、重命名（侧栏或点击对话标题）
- 首次问答后自动请模型拟题（通用设置可关闭；手动改过的标题不会被覆盖）
- 流式回复按「落墨」节奏匀速写出（积压越多写得越快，最多滞后零点几秒），新字带短暂渐显、末尾跟一支笔尖光标；回复元信息里的小印章在书写时呼吸、写完时盖下。「设置 → 个性化」可将界面动效设为开启、随系统或关闭，默认开启
- 分叉：编辑问题或重答不再截断，被换下的那段整段留作一个版本，消息旁以「‹ 2/2 ›」切换；版本可以嵌套（在旧版本里再重答），切换时当前这条停在原位；备份格式随之升到 v4（旧备份可直接导入）
- 引用追问：在回复或自己的话里划选一段文字，浮出「引用」，点击即作为引文带进输入框（可 ✕ 去掉、Esc 去掉、随草稿保存）；发出后显示在问题上方，点击回到出处；送给模型时以 `>` 引块置于问题之前
- 流式回复、停止生成、重答、失败重试、复制；切换对话或新建对话不会打断已有请求，多段对话可在后台同时生成，侧栏显示运行与未读状态；刷新或网络中断时保留已生成正文，并提供“继续生成”；用量在后台统计，只在右上角“余墨”中显示
- 生成时向上翻阅会出现「回到最新」浮标；触屏设备上 Enter 只换行、用按钮发送；侧栏在窄屏下以抽屉打开，点空白处收起；页签标题跟随当前对话
- 输入框旁的「上下文 ≈ …」实时估算下一问会随行送出的内容（上次「另起一纸」之后的问答、系统提示与工具说明、正在输入的文字与待发附件）；超过 24k 时转为印色提醒，前文不再需要时可「另起一纸」
- 新对话与每段旧对话分别保存未发送草稿，文字和待发附件会在刷新、切换对话或打开卷宗后恢复
- Markdown 由 marked 解析、DOMPurify 净化：表格、嵌套列表、任务列表、highlight.js 代码高亮、代码块语言标签与复制按钮、KaTeX 公式（`$…$`、`$$…$$`、`\(…\)`、`\[…\]`）；全部随项目本地分发，其中 KaTeX、mermaid、ECharts、pdf.js 只在首次用到时按需加载，首屏只带 marked + DOMPurify + highlight.js（约 200 KB）；主题、印色与字体由 `theme-boot.js` 在样式解析前写入，暗色模式开页不会先闪一下米白
- 多模型配置、设为默认、连接测试
- 每个模型必须设置独立用量限制，支持 `k`（千）、`m`（百万）、`e`（亿）；未设置时不会发送请求，右上角“余墨”会随用量递减，耗尽后自动结束当前对话
- 支持点击或拖入图片、文本、代码、PDF、Office 等文件；PDF、DOCX、PPTX、XLSX 等会先在浏览器本地提取正文，图片按视觉内容发送，其他二进制文件使用兼容接口的文件内容格式
- 附件原件保存在浏览器 IndexedDB，单次最多 10 件、共 8 MB；PDF 解析器与中文字符映射随项目本地分发，不加载在线资源
- 「卷宗」：侧栏独立页面，跨对话保存常用文件；可从附件卡片按「藏」收入，或在卷宗页直接收入、拖入；按名搜索、按 画 / 文 / 卷 过滤；随时「置于案上」随消息送出，删除对话不会删掉卷宗中的原件
- 图片附件显示缩略图；可直接在输入框粘贴剪贴板图片
- 多轮对话只有本轮要回答的那条消息携带附件原件；更早消息里的文本与提取正文改为摘要（超过 3000 字截断），图片与二进制原件改为占位说明。若要让模型再次看到旧图片，可从卷宗重新置于案上
- 思考模型的 `reasoning_content`，以及部分接口或中转站直接写在正文开头的 `<think>…</think>`，都会显示在紧凑的 `thinking` 折叠区；流式推理时默认展开、正文出现后自动收起，手动开合时尊重用户选择
- 备份可导入（合并策略：按 id 跳过已存在的对话 / 模型 / 卷宗，并合并未冲突的草稿）；导出时可勾选「含附件原件」，这样恢复后附件与缩略图仍可用
- 系统提示词、温度、最大输出长度；新模型的默认 `max_tokens` 为 8192
- 明暗主题、字体、阅读宽度和印色；纸面带细微纸纹，亮色角落是一圈茶渍，暗色右上挂一轮月晕；切换明暗时新主题像洇开的墨一样从右上角侵蚀到左下角，墨缘参差微晕（View Transitions + 位移滤镜遮罩，不支持的浏览器退回颜色渐变）
- 对话备份导出与导入（不会把 API Key 写进备份）
- 工具调用（function calling，可在模型高级配置中关闭）：`search_web` 免 Key 检索（桥接服务抓取 Bing 国际索引，DuckDuckGo 备用）、`fetch_page` 读取网页正文、`read_document` 按页码或关键词翻阅对话附件与卷宗中的文档；全部合并在 `working` 折叠区，每一步以转圈 / ✓ / × 表示运行、成功与失败；同一轮的重复调用直接复用已有结果，手动开合后不会再被自动状态覆盖
- 联网回答结束后从成功的搜索与网页读取步骤生成去重的 `sources` 卡片，已阅读全文的来源会单独标记
- 「言下联网与文档工具」通过本机桥接执行搜索、读网页与读附件；设置内可独立“测试联网”。直接预览 HTML 时，即使先开页面、后启动桥接，也会在发送时自动重连
- 「接口原生联网（实验）」只随请求发送 `enable_search: true`，仅供接口文档明确声明支持的服务使用；它不能替代言下联网
- 页内可视化：```mermaid 代码块渲染流程图 / 时序图 / 结构图，```echarts 代码块（ECharts option 的 JSON）渲染数据图表；完整的 ```html 代码块会在无网络、无父页面权限的隔离沙箱中直接渲染成交互程序。代码尚未写完时以呼吸边框和游走墨光提示，完成后再挂载作品；三类作品均可全屏，图形可下载，HTML 可重启、查看源码与另存为文件
- 消息列表按 id 增量同步：发送、换肤、关闭设置、编辑或重答时只插入、替换或移除有变化的那几条，其余节点（含已画好的图表与 HTML 沙箱）原样保留；明暗、印色或字体变化时图表就地换色
- 长对话按可见消息锚点保存滚动位置；关闭设置、切换对话以及异步图表完成后会回到原阅读位置，发送和重答时才跟随最新内容

如需更换启动端口，可先设置 `YAN_PORT` 环境变量。开发调试时也可显式设置 `YAN_API_CONFIG` 指向一份配置文件；普通启动不会自动读取任何外部配置。
